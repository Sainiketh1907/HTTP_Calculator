Persistent TCP · HTTP/1.1 · C

Calculator server

A small HTTP/1.1 calculator that reads each request, returns an exact Content-Length, and keeps the connection open for the next request.

Supported operations

RequestResponse
GET /add?a=2&b=3200 · 5
GET /sub?a=10&b=4200 · 6
GET /mul?a=6&b=7200 · 42
GET /div?a=9&b=3200 · 3

Run it

cc -std=c11 -Wall -Wextra -O2 -o bserve bserve.c
./bserve ./www 9000

Every HTTP/1.1 request must include a non-empty Host header.
